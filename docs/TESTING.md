# Тестирование

## Автоматические проверки

```bash
npm test         # 90 тестов, около 2 секунд, без интернета и без установки пакетов
npm run check    # синтаксис, ссылки на файлы, офлайн-кеш, обложки и треки
```

Тесты используют встроенный в Node.js `node:test`. Для каждого прогона сервер поднимается на свободном порту с базой **в памяти**, поэтому тесты не трогают рабочую базу и не мешают друг другу.

| Файл | Что проверяется |
|---|---|
| `tests/api.test.js` (68) | здоровье сервера и статика; заголовки безопасности; обход путей (`/../`); каталог и **20 комбинаций фильтров — SQL сервера даёт ровно тот же результат, что клиентская логика**; страница маршрута, 404, GPX; CSRF (без заголовка, чужой Origin), неверный тип содержимого, битый JSON, ошибки валидации, ловушка для ботов, 401 без входа; регистрация (согласие, слабый пароль, повтор почты), вход, профиль, смена пароля, выход аннулирует сессию, выгрузка и удаление данных; избранное, отзывы, планы, списки снаряжения, сообщения о неточностях; администрирование: 403 для пользователя, сводка, модерация с записью в журнал, скрытие маршрута, объявления, защита последнего администратора; ограничение частоты (429) |
| `tests/logic.test.js` (22) | целостность данных (схема маршрута, регионы, 5 категорий доступности, источники, правила, треки у старта); фильтры и подбор; задачи подготовки и их сроки; снаряжение; валидация форм; склонения и форматирование; экранирование в шаблонах и GPX; `safeUrl` |

Вспомогательные функции — `tests/helpers.js` (запуск сервера, клиент с cookie, демо-доступы).

## Сценарии ручной проверки

Запустите `npm start` и откройте <http://localhost:3000>. Ожидаемый результат указан после стрелки.

### Гость

1. **Найти маршрут для человека на коляске.** Каталог → «Передвигаюсь на коляске» → 3 маршрута (Королевский бор, Поозерье без барьеров, экоцентр «Лаура»). Включите «Со мной будет помощник» → 5 маршрутов. Адрес страницы меняется — ссылкой с фильтрами можно поделиться.
2. **Паспорт доступности.** Откройте «Экотропа „Поозерье без барьеров“» → таблица по 5 категориям со статусом и пояснением, условия на тропе, «Коротко и простыми словами», тифлокомментарий, карта с треком, профиль высот с таблицей, правила посещения со ссылками.
3. **Подбор маршрута.** «Подбор» → 4 шага → список с объяснением «почему подходит» и предупреждениями; кнопка «Назад» сохраняет ответы.
4. **Карта.** «Карта» → 25 меток; при отдалении близкие метки раздвигаются, не перекрываются; справа (на телефоне — ниже) тот же список текстом; «Определить моё местоположение» сортирует по расстоянию.
5. **Снаряжение.** «Снаряжение» → выберите маршрут, сезон и участников (например, «Не слышу или плохо слышу») → появляются вещи для слухового аппарата; у каждой вещи — объяснение, общий вес пересчитывается.
6. **Правила.** «Правила» → карточки правил с уровнем, шагами, законом и официальными ссылками; у каждого правила — список маршрутов, где оно действует.
7. **Сравнение.** Отметьте «Сравнить» у трёх маршрутов → внизу появляется панель → таблица сравнения; четвёртый маршрут добавить нельзя — сайт объясняет почему.

### Регистрация и личный кабинет

8. «Войти» → «Регистрация». Отправьте пустую форму → сводка ошибок получает фокус, ссылки ведут к полям. Пароль `12345678` → «Пароль должен содержать буквы и цифры». Без галочки согласия → регистрация невозможна.
9. Зарегистрируйтесь, укажите особенности (например, «Мне трудно ходить») → в каталоге кнопка «Учесть мои потребности из профиля» применяет их к фильтрам.
10. На странице маршрута: «В избранное», «Отметить пройденным», отзыв с оценкой «совпала ли доступность» → отзыв виден на странице, маршрут — в кабинете.
11. **План похода.** «Спланировать поход» → даты в ноябре для маршрута «Большой Иремель» → предупреждение «Даты похода — не в сезон»; список задач подготовки со сроками; отметьте задачу → прогресс меняется; «В календарь (ICS)» скачивает файл; «Карточка безопасности» → страница для печати с маршрутом, контактами и номером 112.
12. Кабинет → «Выгрузить данные (JSON)» → файл со всеми данными пользователя; смена пароля; «Удалить аккаунт» (с подтверждением паролем) → вход под этим аккаунтом невозможен.

### Администратор (`admin@tropy.local` / `Tropy-Admin-2026`)

13. «Администрирование» → сводка с числами; «Отзывы» → скройте отзыв → он пропал со страницы маршрута; «Журнал» → запись о действии.
14. «Объявления» → новое объявление → оно появилось вверху сайта у всех посетителей.
15. «Маршруты» → скройте маршрут → его нет в каталоге и на карте; откройте правку → ошибки формы показываются у полей.
16. Под обычным пользователем откройте `#/admin` → сообщение «Недостаточно прав».

### Доступность

17. **Только клавиатура.** Tab с начала страницы → первые ссылки «Перейти к основному содержанию» и «Перейти к настройкам доступности»; фокус всегда виден; диалоги закрываются Esc; на карте Tab переходит по меткам, Enter открывает подробности.
18. **Экранная читалка** (NVDA + Firefox или Chrome, TalkBack или VoiceOver на телефоне). При переходе по разделам читается заголовок новой страницы; при изменении фильтров — сколько маршрутов найдено; ошибки форм читаются у полей.
19. **Панель «Доступность».** Шрифт 200 % + «Белым по чёрному» + двойной интервал + «Скрыть изображения» → ничего не обрезается и не перекрывается, нет горизонтальной прокрутки; настройки сохраняются после перезагрузки.
20. **Масштаб 400 %** (или ширина окна 320 px) → вся информация доступна, меню — в кнопке «Все разделы сайта».
21. Системные настройки: тёмная тема ОС → схема «Как в системе» тёмная; «Уменьшить движение» → без анимаций; режим высокой контрастности Windows → границы и фокус видны.
22. Автоматически: расширение axe DevTools или Lighthouse → нарушений доступности нет.

### Телефон и офлайн

23. Ширина 360–414 px: нижнее меню, крупные кнопки, фильтры каталога открываются кнопкой «Показать фильтры», таблица доступности перестраивается в карточки.
24. Установите сайт как приложение («Добавить на главный экран»), откройте каталог и маршрут, включите режим полёта → открытые страницы и каталог работают.

### Безопасность (быстрые проверки)

25. `curl -i http://localhost:3000/api/plans` → `401`.
26. `curl -i -X POST http://localhost:3000/api/auth/login -H 'Content-Type: application/json' -d '{}'` → `403 csrf` (нет `X-Requested-With`).
27. Отзыв с текстом `<img src=x onerror=alert(1)>` → показывается как текст, скрипт не выполняется.
28. `curl -i http://localhost:3000/../server/db.js` и `curl -i --path-as-is http://localhost:3000/%2e%2e/server/db.js` → `404`/`400`, исходники сервера недоступны.
29. 21 неверный вход подряд → `429` и сообщение, через сколько минут повторить.

### Автономная версия

30. Откройте `dist/tropy-standalone.html` двойным щелчком → сайт работает без сервера, подпись в подвале — «Автономный демо-режим»; вход под демо-доступом, создание плана и перезагрузка страницы → план сохранён.
