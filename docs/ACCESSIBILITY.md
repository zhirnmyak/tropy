# Доступность сайта «Тропы без барьеров»

Цель — чтобы человек с любыми особенностями здоровья мог **сам** найти подходящий маршрут, понять, что его ждёт на тропе, и подготовиться к походу. Ориентиры: **WCAG 2.2 уровня AA** и **ГОСТ Р 52872-2019** «Интернет-ресурсы… Требования доступности для людей с инвалидностью и других лиц с ограничениями жизнедеятельности».

## Что сделано для разных посетителей

| Кто | Чем помогает сайт |
|---|---|
| **Передвигаются на коляске** (К) | Паспорт доступности маршрута: покрытие, уклоны, места отдыха, инфраструктура; фильтр «Передвигаюсь на коляске» и отметка «со мной будет помощник»; список снаряжения с учётом коляски; советы в плане похода. Все элементы управления — крупные (44 px), сайт удобен с одной рукой на телефоне: нижнее меню и кнопки в зоне большого пальца. |
| **Трудно ходить** (О) | Длина, набор высоты и время в пути видны сразу; варианты сокращения маршрута («доехать до…»), места отдыха; сортировка «сначала короткие». |
| **Не видят или плохо видят** (С) | Полная работа с экранными читалками (NVDA, JAWS, TalkBack, VoiceOver): семантическая разметка, заголовки, ориентиры; **тифлокомментарий** к каждому маршруту; озвучивание текста кнопкой; крупный шрифт до 200 % и контрастные схемы; у карты — текстовый список, у графика высот — таблица; право на собаку-проводника — в базе правил. |
| **Не слышат или плохо слышат** (Г) | Вся информация — текстом, на сайте нет аудио и видео без субтитров; в маршрутах — советы про шумные участки (реки, броды) и договорённость о жестах и сигналах фонарём; в снаряжении — батарейки и влагозащитный чехол для слухового аппарата, карточка-коммуникатор «Я плохо слышу. Пишите или говорите медленно», фонарь для световых сигналов и блокнот. |
| **Нужна простая информация** (У) | Блок «Коротко и простыми словами» — короткие фразы по одной мысли; упрощённый вид; иконки дополняются подписями; подбор маршрута по шагам — одна тема на экране; понятные ошибки форм. |
| **Пожилые, семьи с детьми** | Фильтры «Подходит пожилым», «Можно с детьми», «С детской коляской»; снаряжение для детей; карточка безопасности для близких. |

## Панель «Доступность»

Кнопка «Доступность» есть в шапке на каждой странице (и ссылка «Перейти к настройкам доступности» — первой при нажатии Tab). Настройки применяются мгновенно, сохраняются в браузере и загружаются **до отрисовки** страницы (`boot.js`), поэтому нет «мигания».

| Настройка | Варианты |
|---|---|
| Размер текста | 100 %, 125 %, 150 %, 200 % — вёрстка перестраивается, ничего не обрезается |
| Цветовая схема | как в системе, светлая, тёмная, чёрным по белому, белым по чёрному, тёмно-синим по голубому, коричневым по бежевому, зелёным по тёмно-коричневому (схемы по ГОСТ Р 52872-2019) |
| Шрифт | без засечек, с засечками, удобочитаемый с крупными буквами |
| Расстояние между буквами | обычное, увеличенное, большое |
| Расстояние между строками | обычное, полуторное, двойное |
| Изображения | показывать, чёрно-белые, скрыть и показывать описание |
| Дополнительно | отключить анимацию; выделять ссылки фоном и подчёркиванием; упрощённый вид (одна колонка, крупные кнопки, без декоративных картинок); озвучивание текста и скорость речи |

## Клавиатура

- Все действия доступны без мыши; порядок перехода совпадает с визуальным.
- Заметный индикатор фокуса: рамка 3 px во всех цветовых схемах.
- Ссылки «Перейти к основному содержанию» и «Перейти к настройкам доступности».
- При переходе на другую страницу фокус переносится на её заголовок, обновляется заголовок вкладки.
- Диалоги — нативный `<dialog>`: фокус внутри, Esc закрывает, после закрытия фокус возвращается на кнопку.
- **Карта**: Tab — переход по меткам, Enter — подробности, стрелки — сдвиг, «+» и «−» — масштаб.

## Экранные читалки

- Ориентиры `header`, `nav` (с подписями), `main`, `footer`; один `h1` на странице, иерархия заголовков без пропусков.
- Результаты фильтров и итоги действий объявляются через `aria-live` (например, сколько маршрутов найдено после изменения фильтра).
- Формы: у каждого поля — видимая подпись, подсказки связаны через `aria-describedby`, ошибки — `aria-invalid` и текст у поля; при отправке с ошибками появляется сводка со ссылками на поля и получает фокус. Поля помечены `autocomplete` (имя, почта, пароль), чтобы браузер и менеджеры паролей заполняли их сами.
- Таблица доступности использует роли таблицы и на узком экране перестраивается в карточки без потери связей «категория → статус → пояснение».
- Статусы и сложность передаются **текстом и формой** (иконка, номер, штриховая рамка), а не только цветом.
- Иллюстрации имеют альтернативный текст и подпись «Иллюстрация»; декоративные иконки скрыты от читалок.

## Зрение: контраст, масштаб, перестроение

- Контраст текста и элементов управления ≥ 4,5 : 1 во всех темах; пары цветов проверены скриптом для светлой и тёмной темы, включая метки и треки на карте.
- Сайт работает при ширине 320 CSS-пикселей и масштабе 400 % без горизонтальной прокрутки (WCAG 1.4.10); таблицы перестраиваются с помощью контейнерных запросов.
- Поддерживаются пользовательские интервалы текста (WCAG 1.4.12), `prefers-color-scheme`, `prefers-reduced-motion`, режим высокой контрастности Windows (`forced-colors`).
- На мелком масштабе карты близкие метки раздвигаются, чтобы не перекрывать друг друга и оставаться доступной целью для касания.

## Понятность и безопасность взаимодействия

- Нет капчи: от ботов защищает скрытое поле и ограничение частоты — капча была бы барьером для незрячих и людей с когнитивными нарушениями.
- Нет ограничений по времени; сессия «Запомнить меня» — 30 дней.
- Перед удалением всегда есть подтверждение; ошибки описаны по-русски и подсказывают, как исправить.
- Печатные версии плана, карточки безопасности и списка снаряжения — без меню и лишних элементов.
- Офлайн-режим: сохранённые страницы открываются без связи — важно в горах.

## Как проверяли

- **axe-core** — автоматическая проверка всех страниц (публичных, личного кабинета и администрирования) при ширине 390, 768 и 1366 px, в светлой и тёмной теме и с крайними настройками (шрифт 200 %, белым по чёрному, двойной интервал, без картинок, упрощённый вид): нарушений WCAG 2.2 A/AA нет.
- Скрипт проверки контраста всех пар цветов в темах.
- Проверка отсутствия горизонтальной прокрутки на всех страницах при разных ширинах и размерах шрифта.
- Сценарии ручной проверки с клавиатурой и экранными читалками — в [TESTING.md](TESTING.md).

## Известные ограничения

- Подложка карты (OpenStreetMap) — это изображения стороннего сервиса: её цвета не меняются вместе с темой сайта. Вся информация с карты продублирована текстом.
- Озвучивание использует голоса, установленные в системе; если русского голоса нет, браузер может читать с акцентом.
- Оценки доступности маршрутов основаны на официальных паспортах доступности и открытых источниках. Состояние тропы меняется — поэтому на каждой странице есть кнопка «Сообщить о неточности в доступности», а сообщения разбирает модератор.
